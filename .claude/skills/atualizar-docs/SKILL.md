# Atualizar a documentação

O repositório documenta cada entrega em português, em `docs/`.

1. **Doc da feature:** edite o arquivo existente do assunto (`docs/nino-fase3.md`, `docs/planejamento-de-compras.md`, `docs/analytics.md`, ...) ou crie um novo. Traga data da implementação, o que mudou, como validar (comandos) e o estado (publicado ou só no checkout local).
2. **Implementações futuras:** mova o que foi entregue para fora de `docs/implementacoes-futuras.md` e registre o que sobrou.
3. **Telas:** mudou interface? Atualize `design/inventario/inventario.md` (skill `inventario-e-prototipo-telas`).
4. **Marca e copy:** consulte `docs/branding-casa-mia.md`, `DESIGN.md` e `PRODUCT.md`.

Escreva só o que o código ainda não diz. Não copie trechos de código que vão envelhecer.
